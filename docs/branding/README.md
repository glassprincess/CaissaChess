# Значок Каиссы

Выбран **вариант 01 — «Ферзь и лавр»** ([SVG](caissa-01.svg)).
Он используется в приложении начиная с версии **1.4.1**.

## Эскизы

1. **Ферзь и лавр** — шахматная фигура в лавровых ветвях: игра, мастерство и античное имя.
2. **Муза** — женский профиль с волнистыми волосами, тонкой шеей и лавровым украшением.
3. **Инициал** — открытая буква C обнимает маленькую ферзь; компактный знак для приложения.

Откройте `preview.html`, чтобы сравнить знаки на светлом и тёмном фоне в размерах 24, 48 и 128 пикселей.

Все три SVG имеют прозрачный фон, цвет `#81B64C` и поле `128 × 128`. Шрифтов, растровых вставок и внешних ресурсов в SVG нет. В приложении используется вариант 01.

Для Android adaptive icon знак нужно уменьшить при сборке: важные детали должны помещаться в центральную безопасную область. Эти файлы — исходные знаки, без фоновой подложки и маски Android.
